# AI4BiomedicalDS 第 1 讲练习

课程来源：https://rongshanyu.github.io/AI4BiomedicalDS-plan/#1-ai-yu

## 在 VS Code 打开

1. 打开课程文件夹，然后打开 `lesson01.ipynb`。
2. 点击右上角 **Select Kernel** → **Python Environments**，选择课程文件夹 `.venv` 中的 Python。
3. 点击 **Run All**，应该看到“我的第一个 Notebook 已成功运行”和“检查通过”。
4. 阅读每段代码、每个输出及代码问题说明，按自己的理解补充最后的思考题。

## 文件说明

- `lesson01.ipynb`：Python 运行、pandas 读取、变量说明、描述性统计、代码问题解释。
- `data/demo.csv`：8 条人工模拟记录，不是患者数据。
- `results/descriptive_statistics.csv`：Notebook 生成的统计表。
- `AI使用说明_草稿.md`：待本人补充姓名、学号、科研方向并审核的一页说明。
- `requirements-lock.txt`：此次验证使用的软件版本。
